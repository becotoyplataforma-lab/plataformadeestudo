# 01 — PROJECT

> Visão geral do produto **ConcursoAI Platform**.

## O que é

Plataforma SaaS de preparação para concursos públicos brasileiros com IA.

A missão: **transformar qualquer material autorizado em um professor particular alimentado por IA.**

## Público-alvo

- Concurseiro iniciante
- Concurseiro intermediário
- Concurseiro avançado
- Militar / Área de segurança (PMERJ, CBMERJ, PCERJ, PF, PRF, DEPEN)

## Módulos

| Módulo | Status | Descrição |
| --- | --- | --- |
| **Core** | ✅ MVP | Login, cadastro, perfil, configurações, dashboard |
| **Concurso** | 🚧 Parcial | Disciplinas e cronograma (concursos/editais: futuro) |
| **Question Engine** | ✅ MVP | Questões, resolução, gabarito comentado |
| **Flashcard Engine** | ✅ MVP | Flashcards + revisão espaçada (SM-2) |
| **Analytics** | ✅ MVP | Estatísticas, evolução, tempo estudado |
| **Professor IA** | ✅ MVP | Chat com DeepSeek (V4 Flash/Pro), streaming SSE |
| **Pagamentos** | ✅ Integração | Mercado Pago (checkout + webhook + planos) |
| **Knowledge Engine** | 📋 Pós-MVP | Upload de PDFs/vídeos, OCR, Whisper, embeddings |
| **RAG** | 📋 Pós-MVP | Busca vetorial no Professor IA |
| **Recommendation Engine** | 📋 Pós-MVP | Recomendações personalizadas |
| **Admin** | 📋 Pós-MVP | Gestão de usuários, conteúdo, IA |
